--- ANALYSIS ---

CERVICAL PITCH issue:
  Current range 45° reflects ±22.5° — only the ACTIVE range observed in UI-PRMD.
  Full cervical flex/ext clinical ROM = 120° (AMA guidelines).
  With 45° range: 4.48° error → 0.0995 (looks bad)
  With 120° range: 4.48° error → 0.0373 (more representative)
  Recommendation: use 120° clinical range for fairer comparison.

ANKLE issue:
  Current range 60° reflects ±30° — only the UI-PRMD observed range.
  Full ankle dorsi+plantarflex clinical ROM = ~90° (20°+70°).
  With 60° range:  5.08° error → 0.0847 (looks bad)
  With 90° range:  5.08° error → 0.0564 (more representative)
  Recommendation: use 90° for ankle.

ROOT CAUSE:
  eval_normalized_mad.py uses UI-PRMD DATA RANGES, not clinical ROM limits.
  The docstring says 'clinical limits' but the values match observed UI-PRMD ranges.
  This penalizes joints with small observed variance in the dataset.

RECOMMENDATION:
  Update ANGLE_RANGES in eval_normalized_mad.py to use proper clinical ROM:
  Cervical Pitch: 45° → 120°,  Ankle: 60° → 90°
  This would change overall Normalized MAD: 0.0509 → 0.0412
