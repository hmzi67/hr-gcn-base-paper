💡 KEY INSIGHTS
═══════════════════════════════════════════════════════════════════════════════

  Root Cause 1: Domain Mismatch
  ────────────────────────────────
  H3WB (RGB video) ≠ Vicon (mocap orthographic projection)
  Different sensors, different coordinates, different scale
  → Solution: --from_scratch (learn from scratch, not transfer)

  Root Cause 2: Loss Imbalance
  ────────────────────────────
  11-epoch warmup freezes backbone while untrained head predicts wrong angles
  High angle loss (λ=0.1) overwhelms position learning
  → Solution: --warmup_epochs 3 + --progressive_weights
  → Ramp loss: 0.1x → 0.5x → 1.0x (focus on positions first)

  Root Cause 3: Conservative Learning
  ────────────────────────────────────
  LR=1e-4 too low, batch=256 too large, backbone factor=0.1 too slow
  → Solution: Better hyperparameters for domain adaptation
  → 5x higher LR, 4x smaller batches, 2x faster backbone
